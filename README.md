## 📊 Data Source

All historical performance data in the quilt chart is derived from official **Nifty Indices Total Return Index (TRI)** levels for the period **2015–2026**.

- **Primary Source**: [Nifty Indices - Historical Data](https://www.niftyindices.com/reports/historical-data)
- **Indices Covered**:
  - Nifty 50 TRI
  - Nifty Next 50 TRI
  - Nifty Midcap 150 TRI
  - Nifty Smallcap 250 TRI
